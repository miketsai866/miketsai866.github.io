## `二、深入 Linux（現在～大一寒）`
![icon ><](https://mike-asdf1346.github.io/mid-term/static/assets/img/linux-icon.jpeg)   

安裝不同的 Linux 發行版（Linux Distros），實際操作理解 Linux 系統的組成與運作方式，並培養獨立排除問題的能力。   
以下是我認為現階段應該加強跟未來學習的目標。
### Ubuntu（現在～大一寒假）

### 目標學習

- 熟悉 shell script
- 加強系統管理與問題排除能力

### Arch（大一寒～大一下）
安裝 Arch Linux 能藉此認識 Linux 系統的組成及相關設定 

### 目標學習

- 理解 Linux 發行版與系統組成
- Arch Linux 安裝及基本設定
- 透過手動安裝與設定，認識 Linux 系統的組成、啟動流程及基本運作方式（非 archinstall 安裝腳本）
- 學習錯誤排除及查閱官方文件 ( 如官方網站：[archlinux.org](https://archlinux.org/) )

### OverTheWire（Bandit）（大一下）
主要用來練習基礎 Linux 指令的網站，適合一些剛接觸 linux 的初學者。包括檔案操作、權限、文字處理、SSH、網路工具及一些基本的解題思維等等。 

### 目標學習

- 加強 Linux 指令、檔案操作及權限管理
- 完成所有關卡後，整理各關卡使用的指令、解題思路與相關觀念

## `四、網路基礎（大一下～大二上）`

建立完整的網路基礎，而不是只理解表面就好。希望自己能真正理解不同網路協定的運作方式。   
![三交握 ><](https://mike-asdf1346.github.io/mid-term/static/assets/img/handshake.png)
### 目標學習

- 三向交握（Three-Way Handshake：SYN、SYN + ACK、ACK）
- IP Address 與 Subnet Mask
- Port 與常見網路服務
- TCP 與 UDP
- DNS 的運作原理
- HTTP / HTTPS
- Firewall 基本概念
- 各式網路協定
